# Document Organizer

## 推荐结构

```
<资料根目录>\
├── 学习\
│   ├── 课程名\
│   │   ├── 课件\
│   │   ├── 作业\
│   │   └── 参考\
│   └── ...
├── 电子书\
│   ├── 摄影\
│   ├── 计算机\
│   └── 其他\
├── 项目\
│   └── 项目名\
└── 归档\
```

## 工作流

1. 扫描文件类型和目录：

```powershell
pwsh -File pc-manager.ps1 scan -Drives E
```

2. 按扩展名和目录名识别：
   - `.pdf` / `.epub` / `.mobi` → 电子书或课程资料
   - `.ppt` / `.pptx` / `.docx` / `.xlsx` → 课程/项目
   - `.zip` / `.rar` / `.7z` → 归档或待解压

3. 给出映射表，先 dry-run，再移动。

## 命名规则

- 课程：`学期_课程名`，例如 `研一下_数字系统测试`
- 电子书：`主题_书名`，保留作者和版本
- 项目：`项目名_状态`，例如 `pc-manager_v0.1`
- 不要删除原始文件；重复项移到隔离区。

## 注意

- 课程资料可能含老师姓名、学期、作业，先按 `课程/学期/老师` 分层。
- 不要把可执行文件、安装包混进文档目录。
- 大压缩包先列内容，避免解压出重复文件。
